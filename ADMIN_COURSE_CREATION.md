# Создание курсов администратором

## Описание функциональности

Добавлена возможность для пользователей с ролью ADMIN создавать новые курсы напрямую через веб-интерфейс.

## Изменения в системе

### Backend (без изменений)
Backend уже поддерживает создание курсов через REST API:
- **Endpoint**: `POST /api/courses`
- **Формат**: JSON с полями `title`, `description`, `category`, `authorId`

### Frontend

#### 1. Контроллер (`WebController.java`)
Добавлены новые endpoints:

**GET /courses/create** - Отображение формы создания курса
- Проверяет, что пользователь имеет роль ADMIN
- Если нет прав - перенаправляет на главную с ошибкой

**POST /courses/create** - Обработка отправки формы
- Проверяет права ADMIN
- Отправляет POST запрос на backend API
- При успехе перенаправляет на главную с сообщением об успехе

#### 2. Шаблон формы (`create-course.html`)
Создан новый HTML шаблон с формой для ввода:
- Название курса (обязательное поле, макс. 200 символов)
- Описание (обязательное поле, текстовая область)
- Категория (обязательное поле, макс. 100 символов)
- Кнопки: "Создать курс" и "Отмена"

#### 3. Главная страница (`index.html`)
Добавлено:
- Кнопка "+ Создать курс" (видна только для ADMIN)
- Сообщение об успешном создании курса
- Сообщение об ошибке доступа

#### 4. Стили (`style.css`)
Добавлены стили для:
- Контейнера формы (`.form-container`)
- Текстового поля и textarea (`.form-group textarea`)
- Кнопок действий (`.form-actions`, `.btn-primary`, `.btn-secondary`)

## Как использовать

### 1. Получение прав администратора
Сначала создайте пользователя через регистрацию, затем назначьте ему роль ADMIN через базу данных:

```bash
# Подключитесь к базе данных
docker exec -it education_db psql -U postgres -d education_platform

# Назначьте роль ADMIN пользователю
UPDATE users SET role = 'ADMIN' WHERE username = 'your_username';

# Выйдите из psql
\q
```

### 2. Вход в систему
Войдите в систему под пользователем с ролью ADMIN через веб-интерфейс:
- http://localhost:8081/login

### 3. Создание курса
1. На главной странице (http://localhost:8081/) вы увидите зеленую кнопку "+ Создать курс"
2. Нажмите на кнопку - откроется форма создания курса
3. Заполните все поля:
   - Название курса
   - Описание
   - Категория
4. Нажмите "Создать курс"
5. При успехе вы будете перенаправлены на главную страницу с сообщением "Курс успешно создан!"
6. Новый курс появится в таблице курсов

### 4. Безопасность
- Только пользователи с ролью ADMIN могут видеть кнопку создания
- Попытка доступа к `/courses/create` без прав ADMIN приведет к перенаправлению с ошибкой
- Обе проверки (GET и POST) защищены на уровне контроллера

## Запуск системы

После внесения изменений пересоберите и запустите сервисы:

```bash
# Из корневой директории проекта
docker-compose down
docker-compose up -d --build
```

Проверьте, что все контейнеры запущены:
```bash
docker-compose ps
```

Логи frontend:
```bash
docker-compose logs -f frontend
```

## Тестирование

1. Зарегистрируйте нового пользователя через UI
2. Назначьте ему роль ADMIN через БД (команда выше)
3. Войдите под этим пользователем
4. Убедитесь, что кнопка "+ Создать курс" видна
5. Создайте тестовый курс
6. Проверьте, что курс появился в списке
7. Войдите под обычным пользователем (без роли ADMIN)
8. Убедитесь, что кнопка создания курса не отображается

## Примечания

- Поле `authorId` в текущей реализации устанавливается как `null`
- В будущем можно добавить автоматическое присвоение ID текущего пользователя
- Форма валидируется как на стороне клиента (HTML5), так и на стороне сервера
- При ошибках подключения к backend отображается соответствующее сообщение
